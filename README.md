C++ vs. Python: Qual é a grande diferença?

Eu percebi que elas tem jeitos opostos para resolver os problemas, em cada ponto percebi algo diferente, mas principalmente nos comandos.

C++ tem uma sintaxe Complexa, usa chaves {} e ponto e vírgula ; - Python consegue limpa, legível e usa indentação (espaços)
C++ possui uma velocidade Extremamente rápida (compilada para código nativo) - Python é mais lenta (linguagem interpretada)
C++ tem gerenciamento de Memória Manual(o programador controla os recursos) - Python pode ser automático (feito pelo Garbage Collector)
C++ tem uso Principal em Jogos 3D, sistemas operacionais, robótica, sistemas embarcados - Python tem Inteligência Artificial, Ciência de Dados, automações, web...

Na prática:
Desenvolver em C++ é como conseguir realizar as atividades mais rápido mas sem poder cometer erros;
Desenvolver em Python é como ser prático menos funções e cheg ao resultado mais rápido.
